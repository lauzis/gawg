# Documentation Sync Rule

Whenever a feature is added, changed, or removed, the following must be updated to reflect the current state:

- **README.md** — What it does, Current State, and any relevant sections (Requirements, Usage, etc.)
- **Help page** (`GAWG_Admin::render_help_page` in `includes/class-gawg-admin.php`) — usage instructions and feature descriptions
- Any other documentation files in the repository

Do not ship a feature without updating all three surfaces. Keep them in sync.
